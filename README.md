# Punjab & Haryana Legal AI

A legal research and workflow automation project focused on Punjab & Haryana High Court case law.

## MVP Scope

The first version focuses only on bail-related cases from the Punjab & Haryana High Court.

The goal is to build a clean legal dataset that can later support:

- Case search
- Legal issue matching
- Precedent discovery
- Case summarisation
- Lawyer workflow automation

## First Dataset

The first dataset will contain bail orders and judgments from the Punjab & Haryana High Court.

Initial target:

- 20 manually collected bail cases
- PDF/source link for each case
- Extracted clean text
- Basic metadata
- Case outcome classification
